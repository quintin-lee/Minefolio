## 依赖方向（严格单向）

```
main.c → controllers/*.h
    ↓
controllers/ → services/*.h
    ↓
services/ → repositories/*.h, common/*.h
    ↓
repositories/ → common/db.h ONLY
```

## 核心数据流

### 交易写入流程

```
Vue 组件 → API 层 → http.ts (JWT + CSRF)
    → POST /api/transactions
    → transaction_controller
        → transaction_write_service
            → transaction_repo INSERT (父行)
            → apply_position() 更新资产数量/成本基础/净值
            → balance_apply_delta() 借记关联资金账户
            → if fee > 0: 插入费用子行 (parent_tx_id 关联)
    → respond_ok() 返回 {code:0, data:{id,...}}
```

### 交易删除流程（含费用回滚）

```
1. 查询所有费用子行 tx_child_fee_rows()
2. 反转每行费用余额 delta balance_apply_delta()
3. 删除费用子行 tx_delete_fee_children()
4. 删除父交易
```

## 主要模块

### 后端模块

| 模块 | 职责 |
|------|------|
| auth | 用户注册/登录/JWT |
| transaction | 交易 CRUD + 余额联动 |
| asset | 投资追踪（股票/基金/债券/加密货币）|
| category | 支出/收入分类 |
| ai | AI 财务助手（工具调用）|
| report | 持仓/支出/资产报表 |
| daily_expense | 每日消费追踪 |
| cashflow | 收支流动分析 |
| transfer | 账户间转账 |
| ledger | 多账本/空间支持 |
| market | 价格历史和市场数据 |
| dca | 定投计划 |
