# 仪表盘 Bento Grid 重构与核心流水页面质感升级设计规范 (Bento Dashboard & Ledger Modernization Design Spec)

- **日期**: 2026-09-11
- **状态**: Approved by User
- **风格定位**: Linear / Raycast 级现代深色高质感金融科技风（Bento Grid 模块化网格、深色微光边框、细腻磨砂毛玻璃、金融科技蓝紫/翡翠绿渐变、等宽金融排版）
- **核心范围**: 
  1. 仪表盘大盘重塑（`Dashboard.vue`）
  2. 高阶图表微动效与渐变（`NetWorthChart.vue`, `AssetBreakdownPie.vue`, `YearlyChart.vue`, `echarts-theme.ts`）
  3. 收支流水与交易记录流式卡片化（`Transactions.vue`, `DailyExpenses.vue`）
  4. 记账弹窗与加载骨架屏质感（`DailyExpenseForm.vue` / 记账 Dialog, Skeleton）

---

## 1. 背景与目标 (Background & Goals)

在完成了基础设计系统升级（Design Tokens 与基础 SummaryCard）之后，当前 Minefolio 的页面结构仍存在以下视觉与交互痛点：
1. **仪表盘结构单一**：顶部依然是机械对称的 4 张等宽统计卡片，缺乏第一视觉锚点；多币种折算条以生硬横幅的形式撕裂页面。
2. **图表交互与色彩平淡**：净资产折线图缺少科技感呼吸发光与时间粒度快速切片，饼图未形成空心 Donut 与中央指标联动，年度收支柱状图缺少圆角和微渐变。
3. **流水页面偏传统后台**：`Transactions.vue` 与 `DailyExpenses.vue` 依然使用厚重的表格边框，分类与账户缺少直观的视觉胶囊，金额排版未达到消费级 App 的沉浸感。

**核心目标**：
- **Bento Grid 布局**：在 `Dashboard.vue` 建立不对称但平衡的 Bento Grid 视觉重心，突出「净资产 Hero 大卡」。
- **一体化多币种**：将多币种折算条无缝吸纳进 Hero 卡片底部，化作微型多币种配比条。
- **高阶图表品质**：赋予折线图 Linear 科技蓝紫发光曲线与毛玻璃悬浮 Tooltip；环形图升级为带圆角的 Donut Ring，中心动态呈现数值联动。
- **轻量流式卡片行**：流水与交易列表去除厚重边框，采用悬浮悬停微上浮的流式卡片行，分类与账户配带柔底徽章。

## 3. 详细设计规范 (Detailed Specifications)

### 3.1 Dashboard Bento Grid 布局规范 (`Dashboard.vue`)

#### 1. Hero 净资产主卡 (`stat-hero-card`)
- **布局定位**：桌面端占据约 58%（`:md="14"`），次级卡片组占据 42%（`:md="10"`）。
- **视觉层级**：
  - 背景：`linear-gradient(135deg, rgba(59, 130, 246, 0.12) 0%, rgba(15, 23, 42, 0.85) 100%)`。
  - 边框：`1px solid rgba(59, 130, 246, 0.35)`，顶部带 1px 霓虹蓝高光线。
  - 金额：`font-size: 34px; font-weight: 700; font-family: var(--mf-font-mono);`，货币符号单独包裹为小号弱化样式（`font-size: 20px; opacity: 0.65;`）。
  - Sparkline：SVG 曲线采用渐变描边，末端嵌入带 CSS 呼吸动效（`animation: pulse-glow 2s infinite`）的圆点。
  - 涨跌胶囊：实时计算 7 日或近 30 日变动，显示如 `+1.42%` 翡翠绿胶囊。
- **一体化多币种微型配比条 (`multi-currency-mini-strip`)**：
  - 将原页面中突兀的大横幅精炼为 Hero 卡片底部的紧凑分段进度条。
  - 每个币种段按比例展示（如 CNY 70%, USD 25%, EUR 5%），支持 Hover 显示原币与折算值，点击直接切换当前基准币种。

#### 2. 次级 Bento 指标组
- 三张卡片纵向均分或紧凑排列：
  - **总资产**：图标底色 `rgba(59, 130, 246, 0.15)`，文字高亮。
  - **总负债**：标注资产负债率微型百分比（`Debt Ratio: XX%`）。
  - **本月结余**：根据金额正负自动应用翡翠绿或琥珀橙微光，内置收支差额微指示。

### 3.2 ECharts 金融可视化质感重塑

#### 1. 净资产历史走势图 (`NetWorthChart.vue`)
- **渐变折线与光晕**：
  - 线条：`lineStyle: { width: 3, color: new echarts.graphic.LinearGradient(0, 0, 1, 0, [{ offset: 0, color: '#3b82f6' }, { offset: 1, color: '#6366f1' }]), shadowColor: 'rgba(99, 102, 241, 0.45)', shadowBlur: 14 }`。
  - 渐变填充：从 `#3b82f6`（不透明度 0.25）平滑淡出到 `rgba(59, 130, 246, 0.0)`。
- **高阶悬浮指示与 Tooltip**：
  - 十字光标启用发光指示线。
  - Tooltip 使用毛玻璃容器样式，支持展示当前点金额与较首日涨跌幅。
- **时间范围切片组件**：卡片 Header 右侧提供 `30D | 90D | 1Y | 全部` 的切换胶囊，动态过滤折线数据。

#### 2. 资产分布 Donut 环形图 (`AssetBreakdownPie.vue`)
- **空心圆环比例**：`radius: ['58%', '76%']`。
- **扇区微圆角**：`itemStyle: { borderRadius: 6, borderColor: 'var(--mf-surface-card)', borderWidth: 3 }`。
- **中心动态指标联动**：
  - 默认中心文本：`总资产`（小字） + 格式化总金额（大字）。
  - 鼠标悬停某一分类时，中心文本动态切换为：`分类名` + `分类金额` + `占比百分比`。
- **高质感调色盘**：集成电光蓝 (`#3b82f6`)、霓虹紫 (`#8b5cf6`)、翡翠绿 (`#10b981`)、暖琥珀 (`#f59e0b`)、珊瑚粉 (`#ec4899`)、天青蓝 (`#06b6d4`)。

#### 3. 年度收支对比柱状图 (`YearlyChart.vue`)
- **柱顶微圆角**：`borderRadius: [4, 4, 0, 0]`。
- **渐变填充**：
  - 收入柱：`#10b981` → `#059669`；
  - 支出柱：`#f43f5e` → `#e11d48`。
- **Hover 光效**：单月悬停时触发阴影高亮，清晰呈现收支净差额提示。

### 3.3 收支流水与交易记录流式卡片化 (`Transactions.vue` & `DailyExpenses.vue`)

#### 1. 流式悬浮行 (Floating Streamlined Rows)
- 表格去除硬质单元格垂直线，表格行背景默认为透明微光。
- Hover 悬停时整个数据行背景变为 `rgba(30, 41, 59, 0.65)`，并在左边缘呈现 2px 科技蓝指示条。
- 行与行之间采用细微渐变分割线（`rgba(255, 255, 255, 0.05)`）。

#### 2. 分类与账户胶囊化 (Iconic Badges)
- 分类标签：采用轻量半透明圆角药丸（Pill），配合柔和色调。
- 资产账户：采用极简灰色微光小胶囊，与分类明显区分。
- 金额展示：采用专属金额类 `.mono-amount`，大号加粗，收入采用柔和绿加号光效，支出采用柔和红减号光效。

#### 3. 记账弹窗交互打磨 (`DailyExpenseForm.vue` / 记账 Dialog)
- 对话框采用 `backdrop-filter: blur(24px)` 毛玻璃背景与 1px 微光边框。
- 金额输入框采用大字号 Hero Input（28px 字号，居中或清晰对齐，自动前置大字号货币符号）。
- 快捷分类选择与标签选择器做深色主题适配，消除任何 Element Plus 默认生硬色块。

## 4. 验证与测试策略 (Verification Strategy)

1. **前端静态检查与编译构建**：
   - 执行 `npm --prefix frontend run build`，确保 TypeScript 检查与 Vite 打包通过（0 警告，0 错误）。
   - 执行 `npm --prefix frontend run build:mobile`，确保移动端模式构建通过。
2. **自动化测试套件**：
   - 执行 `npm --prefix frontend test`，确保 45 项单元测试 100% 通过。
   - 保证现有路由、API 调用、Pinia store 状态保持 100% 兼容。
3. **视觉走查验证**：
   - 检查暗色模式（Dark）与亮色模式（Light）下的对比度、边框微光和图表文字清晰度。
   - 检查不同屏幕分辨率（1920px、1440px、1280px、移动端折叠）下的自适应断点与网格流。
